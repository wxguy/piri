# Issues and Help

## Before opening an issue

Run:

```bash
piri --version
piri --doctor
piri --formats
piri --backends
```

Include relevant output in the issue.

## Bug reports

Provide:

- piri version
- Python version
- operating system
- architecture
- native backend versions
- command used
- complete error message
- minimal reproducible example

Do not upload confidential archives.

## Feature requests

For a new archive format, explain:

- format name
- required native tools/libraries
- read/write requirements
- expected platform support
- licensing considerations
- security implications

## Security issues

Do not publish sensitive security vulnerabilities in a public issue. Follow the project's security policy.
