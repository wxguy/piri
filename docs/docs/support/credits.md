# Credits

piri is an open-source project by [**WxGuy**](https://wxguy.in/) with the help of செயற்கை நுண்ணறிவு.

The project builds on the excellent work of the open-source communities behind tools and libraries such as:

- GNU tar
- gzip / pigz
- Zstandard
- XZ Utils
- bzip2 / pbzip2
- LZ4
- Info-ZIP
- 7-Zip
- libarchive / bsdtar
- CPIO
- QEMU utilities
- Linux filesystem tools
- Python

piri does not attempt to replace these mature tools. Its purpose is to provide a consistent, safe and automation-friendly interface around the capabilities available on a system.
